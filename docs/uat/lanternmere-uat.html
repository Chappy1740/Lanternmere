Ground rules (from the runbook)
  • Use test accounts and test-only Lodges and Guilds. Agree on cleanup before creating or deleting hosted records.
  • Log date, Worker build, role, what you did, expected and actual result.
  • Use role labels like "Owner" or "Second account", not names or account IDs.
  • Never type passwords, email links, OAuth codes, tokens or API keys into this page or chat.
  • A failure stops that check. Keep enough safe detail to reproduce it, then move on to independent checks.
  • A local build or a page that loads is supporting evidence only. A check passes on the real hosted flow.
  • This page does not change the tracker. GitHub stays the source of truth; your notes live only in this browser.
